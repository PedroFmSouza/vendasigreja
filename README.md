# Vendas Igreja

Aplicativo mobile desenvolvido em **Flutter** para gestão de vendas de uma igreja (ex: produtos, livros, materiais, eventos, bazares etc.), com suporte a **Android** e **iOS**.

> ⚠️ Este README foi gerado a partir da estrutura pública do repositório (projeto Flutter em estágio inicial, com pastas `android`, `ios`, `lib` e `test`). Como o código-fonte dentro de `lib/` não estava disponível para análise detalhada, as seções de **Funcionalidades** e **Tecnologias** abaixo são uma estrutura sugerida — ajuste conforme o que já está implementado no app.

## 📖 Sobre o projeto

O **Vendas Igreja** tem como objetivo facilitar o controle de vendas realizadas por uma igreja ou comunidade, permitindo registrar produtos, acompanhar vendas e gerar relatórios simples de forma prática, direto do celular.

## 🚀 Como executar o projeto

### Pré-requisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado e configurado
- Um emulador Android/iOS configurado ou um dispositivo físico conectado
- Editor de código (recomendado: [VS Code](https://code.visualstudio.com/) ou [Android Studio](https://developer.android.com/studio))

### Passo a passo

1. Clone o repositório:
   ```bash
   git clone https://github.com/PedroFmSouza/vendasigreja.git
   cd vendasigreja
   ```

2. Instale as dependências:
   ```bash
   flutter pub get
   ```

3. Verifique se tudo está configurado corretamente:
   ```bash
   flutter doctor
   ```

4. Execute o aplicativo:
   ```bash
   flutter run
   ```
